# Melgaard Park Disc Golf — Interactive Scorecard

A free, mobile-friendly interactive scorecard for the 9-hole Melgaard Park Disc Golf Course in Aberdeen, South Dakota.

## Play online

**Interactive scorecard:** https://raw33.github.io/Melgaard-disc-golf/

## Features

- Hole-by-hole scoring for multiple players
- Quick score entry with Previous / Next navigation and direct 1–9 hole selection
- Tee-to-basket map perspective for each hole
- Between-hole walking guidance to the next tee
- Local browser autosave
- Missing-score check before completing a round
- Clean end-of-round summary
- Shareable social scorecard image
- QR code on shared scorecards linking back to the interactive scorecard
- Official Aberdeen Parks, Recreation & Forestry course-information link
- Offline-capable single-file design with the course map embedded directly in `index.html`

## Official course information

Melgaard Park Disc Golf is a City of Aberdeen Parks, Recreation & Forestry course. Official course information, including the City-provided map/scorecard, is available at:

https://www.aberdeen.sd.us/1076/Disc-Golf-at-Melgaard-Park

## About this project

This interactive scorecard was created independently by [Councilman Rich Ward](https://richward.org) out of a love for Aberdeen Parks, Recreation & Forestry and disc golf. It was built as a personal side project to make phone-based scorekeeping easier, uses no City funds, and is made available free for the public to enjoy.

This is an unofficial companion tool and is not an official City of Aberdeen application. Course imagery and information are based on materials made publicly available by Aberdeen Parks, Recreation & Forestry.

## Technical notes

The project is intentionally simple: the published site is a single `index.html` file and does not require a build process or separate image assets. GitHub Pages serves the file directly from this repository.
