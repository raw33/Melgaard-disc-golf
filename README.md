# Melgaard Park Disc Golf — Interactive Scorecard

A single-page, mobile-friendly interactive scorecard for the 9-hole Melgaard Park Disc Golf Course in Aberdeen, South Dakota.

## What is included
- Hole-by-hole play mode
- Tee-to-basket course-map perspective
- Between-hole walking guidance
- Multi-player scoring
- Local browser autosave
- End-of-round missing-score check
- Shareable 4:5 PNG scorecard
- Native mobile share sheet when supported
- Fallback PNG save when file sharing is unavailable
- Link back to the official City of Aberdeen disc golf page

## Deployment
Upload `index.html` to any static web host. For GitHub Pages, place this file in the root of the published branch.

The page contains the course map inline and does not require a separate image asset to function.
